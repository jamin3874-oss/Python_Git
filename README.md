# Python_Git

과제 코드와 공부주머니 앱을 보관하는 저장소입니다.

## 공부주머니 · Study Pocket

여러 PDF를 모아 시험 공부 노트를 만들고 AI와 대화하는 모바일 설치형 웹 앱(PWA)입니다.

- [앱 열기](https://study-pocket-six.vercel.app)
- [앱 소스와 실행 안내](study-pocket/README.md)
- [개발 과정·기획·검증·배포 문서](study-pocket/docs)

앱은 `main` 브랜치의 `study-pocket/`에 있습니다. Vercel의 Root Directory는 `study-pocket`이며, `main`에 push하면 자동 배포합니다. API 키는 앱의 설정창에서 본인 키를 입력합니다.

기존 `1차 과제`, `2차 과제`, `3차 과제`, `Term Project`는 각 폴더에서 확인할 수 있습니다.
