# 나만의 프롬프트 관리 프로그램

GenAI 미션을 진행하며 작성했던 프롬프트들을 체계적으로 관리하기 위한 콘솔 기반 Python 프로그램입니다.

## 실행 방법

1. Python 3.10 이상이 설치되어 있어야 합니다.
2. 터미널에서 아래 명령어로 실행합니다.

\`\`\`bash
python main.py
\`\`\`

3. 메뉴에 표시되는 번호를 입력하여 원하는 기능을 선택합니다.

## 기능 목록

| 번호 | 기능 | 설명 |
|---|---|---|
| 1 | 프롬프트 추가 | 제목, 내용, 카테고리를 입력해 새 프롬프트를 등록합니다 |
| 2 | 프롬프트 목록 | 저장된 모든 프롬프트를 번호와 함께 보여줍니다 |
| 3 | 프롬프트 삭제 | 번호를 입력해 프롬프트를 삭제합니다 |
| 4 | 카테고리별 조회 | 선택한 카테고리에 속한 프롬프트만 보여줍니다 |
| 5 | 프롬프트 검색 | 키워드로 제목/내용을 검색합니다 |
| 6 | 프롬프트 상세 보기 | 번호를 입력해 프롬프트 전체 내용을 확인합니다 |
| 7 | 즐겨찾기 관리 | 번호를 입력해 즐겨찾기를 추가/해제합니다 |
| 8 | 즐겨찾기 목록 | 즐겨찾기한 프롬프트만 모아서 카테고리순으로 보여줍니다 |
| 0 | 종료 | 프로그램을 종료합니다 |

## 프롬프트 카테고리

- 텍스트 생성
- 이미지 생성
- 영상 생성
- 페르소나
- 자동화
- 기타

## 기본 등록 데이터

프로그램 시작 시 이전 미션에서 실제로 작성했던 프롬프트 3개가 기본으로 등록되어 있습니다.

1. 협업 요청 메일 어시스턴트 (케이) — 페르소나
2. 배달모아 광고 씬1 - 원룸 고민 장면 — 영상 생성
3. 도로 안전 뉴스 자동화 워크플로 설계 요청 — 자동화
