# 공부주머니 · Study Pocket

특정 과목에 종속되지 않는 PDF 시험 공부 앱입니다. 여러 PDF를 모아 전체 노트를 만들고 질문을 이어갑니다. **HTML/CSS/JavaScript + Python 3.12 이상**으로 동작하며 프론트 프레임워크와 외부 CDN이 없습니다. PDF 파싱·그림 렌더링은 함께 제공하는 Mozilla PDF.js를 사용합니다.

## 실제 Vercel 배포

### [공부주머니 앱 바로 열기](https://study-pocket-six.vercel.app/)

PC와 휴대폰에서 사용할 주소는 **https://study-pocket-six.vercel.app/** 입니다. 이 주소는 로컬 서버를 켜지 않아도 열 수 있으며, 다른 사람에게 공유할 때도 사용합니다.

2026-11-11에 GitHub 저장소를 Vercel `jaemin13/study-pocket` 프로젝트에 연결했습니다. 2026-11-12에 앱 브랜치를 `main`으로 병합하고 프로덕션 브랜치도 `main`으로 전환했습니다. 앱 루트는 `study-pocket`이며, `main`에 push하면 Vercel이 새 배포를 생성합니다. 기존 개발 브랜치는 기록으로 유지합니다.

2026-11-12 서버 AI 연결을 추가했습니다. **AI 연결 → 앱 접속 코드 → 서버 AI에 연결**을 한 번 진행하면 같은 브라우저에서 30일 동안 사용할 수 있습니다. API 키는 Vercel의 암호화된 환경변수에서 읽으며 브라우저로 보내지 않습니다. 기존 앱이 남아 있으면 모든 공부주머니 탭을 닫고 다시 열거나 **앱 업데이트**를 누르세요. 초기화 오류와 PDF 저장 오류는 화면에 표시하며, 업데이트 때 저장된 PDF·노트를 삭제하지 않습니다.

실제 배포 URL의 정적 리소스·PWA·Python API 오류 응답을 검사했고, Codyssey `claude-opus-4-8`에서 텍스트 응답 및 합성 JPEG 계산 이미지의 정답 `5`를 확인했습니다. 키는 기존 환경변수에서 메모리로만 사용했고 요청은 총 2회였습니다. 큰 PDF 전체의 실제 모델 정확도, 휴대폰 실기기 및 브라우저 클릭 검증은 별도입니다. 근거는 `docs/04_배포및사용안내/Vercel_배포완료_2026-11-11.md`와 검증 JSON에 있습니다.

## 이 PC에서 개발용 서버 실행

Node.js 22.13 이상과 Python 3.12 이상을 설치한 뒤 이 폴더에서 실행합니다. 별도 npm/pip 라이브러리 설치는 필요하지 않습니다.

```powershell
npm run build
python -B server.py
```

서버가 실행되면 [이 PC의 로컬 앱 열기](http://127.0.0.1:8788)를 누릅니다. `run.ps1`도 동일한 작업을 합니다. 이 주소는 **서버를 실행한 PC에서 서버가 켜져 있는 동안에만** 열립니다. 실행 터미널을 종료하면 접속할 수 없습니다.

`127.0.0.1`은 접속하는 기기 자신을 뜻하므로 휴대폰에서 PC의 앱에 연결하는 주소가 아닙니다. 휴대폰 사용·설치와 다른 사람에게 공유할 때는 위의 [Vercel 배포 주소](https://study-pocket-six.vercel.app/)를 사용하세요.

## 사용

1. 자료실에서 여러 PDF를 선택합니다. 각 150MB 이하이며 원본을 IndexedDB에 저장합니다.
2. **AI 연결**에서 관리자가 제공한 **앱 접속 코드로 한 번 연결**합니다. 개인 키로 쓰려면 선택 사항인 개인 API 키 입력란을 사용할 수 있습니다. 기본 모델 ID는 `claude-opus-4-8`이며 사용 권한은 실제 연결 확인으로 검사할 수 있습니다.
3. 공부 노트에서 원하는 설명 방식·분량·제외 범위 등을 적고 **PDF 전체로 공부 노트 만들기**를 누릅니다.
4. 전체 내용을 자동으로 읽고 계층적으로 연결한 단일 노트를 받습니다. 중단 후 같은 설정으로 이어갈 수 있습니다.
5. 작은 손글씨는 원본 보기에서 영역을 드래그해 확대 판독하고, 수정 후 다음 전체 노트에 반영합니다.
6. AI 대화에서 일반 질문 또는 선택한 완성 노트에 관한 후속 질문을 보냅니다.
7. 잘못 올린 PDF는 파일 옆 ×로 삭제합니다. 그 자료가 포함된 통합 노트·진행 기록·프로젝트 대화도 제거합니다. PC 원본 파일은 삭제하지 않습니다.

## API 키

서버 AI는 Vercel의 `CODYSSEY_API_KEY` 환경변수를 사용합니다. 별도의 앱 접속 코드(`STUDY_APP_ACCESS_TOKEN`, 무작위 32자 이상)를 한 번 입력하면 서버가 서명한 30일 로그인 쿠키를 발급합니다. 배포 HTTPS 쿠키에는 `Secure`, `HttpOnly`, `SameSite=Strict`를 적용합니다. 실제 API 키와 접속 코드는 localStorage·IndexedDB·내보내기·소스에 저장하지 않으며, API 키를 프론트엔드로 내려주지 않습니다. 새로고침과 재방문 때 로그인 쿠키로 인증합니다. 다른 기기, 쿠키 삭제, 만료 후에는 다시 연결합니다. 연결 해제는 AI 연결 창에서 할 수 있습니다.

개인 API 키 입력도 선택 기능으로 유지하며 그 키는 현재 탭 메모리에서만 사용합니다. AI 실행 시 고정 주소 `https://copa.codyssey.kr/v1/messages`를 호출합니다. Anthropic Messages 규약의 `x-api-key`, `anthropic-version: 2023-06-01`을 사용합니다. 리디렉션과 자동 유료 재시도는 차단합니다.

서버 키를 쓰려면 배포 환경에 `CODYSSEY_API_KEY`와 `STUDY_APP_ACCESS_TOKEN`을 모두 등록하고 재배포합니다. 서버 키만 등록한 상태나 로그인하지 않은 방문자는 소유자의 키를 사용할 수 없습니다. **접속 코드를 받은 사람은 서버 키의 사용량을 소비할 수 있으므로 허용할 사람에게만 전달하세요.** 키와 접속 코드는 GitHub·README·제출 ZIP에 넣지 마세요. PC 환경변수가 Vercel로 자동 복사되는 것은 아닙니다. 현재 서버 로그인 기능은 Vercel/Python 서버용이며, 별도 Sites Worker는 기존 개인 키 입력 방식을 유지합니다.

## 모바일 설치·저장

- Android Chrome: 메뉴 → 앱 설치/홈 화면에 추가.
- iPhone Safari: 공유 → 홈 화면에 추가.
- PWA manifest, 192/512px 아이콘, maskable 아이콘, 서비스 워커, 모바일 하단 메뉴 및 safe area를 포함합니다.
- 앱 셸과 저장된 노트는 설치·최초 로딩 이후 오프라인에서 열 수 있습니다. PDF.js의 추가 폰트/압축 해독 리소스는 한 번 사용해 캐시한 이후 오프라인 사용이 가능하며, 모든 형식의 PDF 오프라인 렌더링을 보장하지 않습니다.
- PDF·노트·대화는 **이 기기의 브라우저**에 저장됩니다. 계정 및 기기 간 자동 동기화는 없습니다. 브라우저 데이터 삭제·저장 용량 부족·OS의 저장소 정리로 자료가 사라질 수 있어 노트 다운로드를 권장합니다.
- 앱 공유는 사이트 주소만 공유합니다. 다른 사람에게 내 PDF와 노트가 자동 공개되지 않습니다.

## 전체 PDF 처리 구조와 한계

PDF 원본 저장 때 모든 페이지 이미지를 미리 생성하거나 서버로 올리지 않습니다. 분석 시작 때 쪽수를 확인하고 필요한 페이지를 순서대로 렌더링합니다. 한 요청당 최대 4쪽, 이미지 합계 2.35MB, 요청 JSON 3.8MB로 제한합니다. 전체 쪽수에는 150쪽 같은 고정 중단 조건이 없습니다. 중간 노트를 최대 4개·58,000자씩 통합하여 마지막 한 권으로 만듭니다. 501쪽 전체 흐름은 모의 모델로 검증했습니다.

완료한 묶음마다 IndexedDB에 체크포인트를 저장합니다. Web Locks로 같은 브라우저의 중복 AI 작업을 막고, 저장 직전 원본·요청 버전을 재검사합니다. 탭을 닫거나 휴대폰이 앱을 절전하면 실행이 중단될 수 있습니다. 응답 수신 후 저장 전에 앱이 종료되면 그 한 요청은 재실행될 수 있습니다. 유료 요청을 서버 백그라운드에서 계속 돌리는 구조는 아닙니다.

기본 155 DPI, 정밀 200 DPI, 전체 페이지 긴 변 최대 2400px입니다. 작은 필기 영역은 원본에서 최대 300 DPI·1800px로 렌더링합니다. DPI는 픽셀 밀도이며 실제 인식 정확도를 보장하지 않습니다. 스캔 글자·필기·그림을 이미지로 보내는 비전 분석이며 별도의 Tesseract OCR 엔진을 사용하지 않습니다. 선명한 텍스트 레이어도 보조 입력으로 전달합니다. X는 사용자가 개인 범위 제외를 요청했을 때 적용하며 OX 문항 답과 구별하도록 지시합니다.

대용량 PDF는 기기 메모리와 저장 공간의 영향을 받습니다. 저사양 휴대폰에서 150MB 문서가 항상 열리는 것은 아닙니다. 수백 쪽은 여러 유료 호출이 필요하고 통합 과정에서 세부 정보가 요약될 수 있습니다.

## Vercel 배포

이 저장소를 Vercel에서 Import할 때 Root Directory를 `study-pocket`, 프로덕션 브랜치를 `main`으로 지정합니다. Framework는 Other, Build Command는 `npm run build`, Output Directory는 `dist/public`입니다. `vercel.json`이 함께 제공됩니다. `/api/ai`는 `api/ai.py`로 처리합니다. Python 함수 최대 실행 시간을 300초로 선언했고 API 자체 타임아웃은 135초입니다. 실제 적용 가능 시간·요청 한도는 계정 플랜과 Vercel의 현재 설정에 따릅니다.

공식 참고: [Vercel Python runtime](https://vercel.com/docs/functions/runtimes/python), [Vercel configuration](https://vercel.com/docs/project-configuration/vercel-json), [MDN PWA 설치 조건](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable).

## 검사

```powershell
npm test
python -B -m unittest discover -s tests -p "test_*.py" -v
# 로컬 서버를 실행한 뒤:
python -B tests/http_check.py http://127.0.0.1:8788
```

JavaScript 32개, Python 21개 테스트로 기존 PDF 전체 처리와 서버 로그인·쿠키 위변조·만료·로그아웃을 검사합니다. 별도로 DOM·IndexedDB 모의 환경에서 두 PDF의 원본 저장, 노트 화면 전환, 잘못된 PDF의 비파괴 거절을 검사했습니다. 이 검사는 실제 브라우저 파일 선택기 검증을 대신하지 않습니다. 2026-11-11 실제 Vercel 배포의 텍스트·이미지 모델 요청 2회도 확인했습니다. 자료 전체의 학습 정확도와 휴대폰 설치 완료는 별도 확인이 필요합니다.

2026-11-12 추가로 **실제 서버 키와 로그인 쿠키**를 사용해 합성 2쪽 PDF → PDF.js 이미지 렌더링 → 전체 공부 노트 → 후속 대화를 검사했습니다. 노트와 후속 대화의 예제 정답을 확인했고 실제 모델 요청은 2회였습니다. 클라이언트에서 API 키를 보내지 않았습니다. 이 검사는 Node에서 실행한 실제 PDF 처리·API 통합 검사이며 브라우저 파일 선택·휴대폰 실기기 검사와 구별합니다. 기록: [서버 AI 실제 검사](docs/03_검증자료/서버_AI_실제검사_2026-11-12.json).

`worker/api.mjs`와 빌드 시 생성하는 `dist/server/index.js`는 Sites용 추가 호스팅 어댑터입니다. Vercel에서는 사용하지 않습니다. `.openai/hosting.json`은 이 Sites 실행본의 식별 설정이며, 새로운 제출 저장소에 복사할 필요는 없습니다.

## 외부 라이브러리

`vendor/pdfjs/`는 기존 프로젝트에 설치되어 있던 `pdfjs-dist` 5.7.284의 legacy 호환 빌드을 복사한 정적 배포 파일입니다. Apache License 2.0이며 `vendor/pdfjs/LICENSE`를 포함합니다. 나머지 앱 런타임은 브라우저 API 및 Python 표준 라이브러리입니다.
