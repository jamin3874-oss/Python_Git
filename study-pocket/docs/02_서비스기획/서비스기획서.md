# 공부주머니 서비스 기획서

## 서비스 개요

시험공부를 위해 여러 PDF와 필기를 읽어야 하는 학습자에게, 전체 내용을 연결한 노트와 대화형 설명을 제공합니다. 사용자가 정한 범위와 공부 방식을 AI 요청에 반영합니다. 특정 전공·학교·과목을 전제로 하지 않습니다.

목표 사용자는 PDF 강의자료를 자주 사용하는 학생, 자격증 수험생, 학습 자료를 직접 정리하는 일반 학습자입니다. 핵심 문제는 자료가 흩어지고, 작은 필기와 그림이 요약에서 빠지며, 슬라이드마다 수동으로 정리해야 한다는 것입니다.

## 화면과 핵심 흐름

| 화면 | 주요 기능 | 다음 행동 |
|---|---|---|
| 자료실 | 여러 PDF 가져오기, 이전 공부 선택, 삭제, 체험용 예시 | 공부 노트로 이동 |
| 공부 노트 | 자유 요청, 전체 자동 처리, 중단·이어가기, 결과 다운로드 | 결과 읽기·확대 판독·질문 |
| 원본 도구 | PDF 페이지 보기, 영역 드래그, 손글씨 판독 수정 | 수정한 판독으로 전체 노트 새로 만들기 |
| AI 대화 | 일반 질문, 완성 노트 선택, 후속 질문, 실패 질문 재전송 | 이해될 때까지 대화 |
| 설정·설치 안내 | 키·모델 설정, 실제 연결 확인, PWA 설치 도움말 | 개인 키로 사용 |

모바일에서는 세 주요 화면을 하단 메뉴로 제공합니다. 폰트·입력란·버튼·패딩은 좁은 화면에 맞추고, 홈 화면 설치 및 기기 safe area를 고려했습니다.

## AI 기능과 처리 원리

1. PDF 원본은 브라우저 IndexedDB에 저장합니다. 저장 단계에 서버 업로드가 없습니다.
2. PDF.js가 분석할 페이지를 JPEG로 렌더링하고 텍스트 레이어를 보조로 추출합니다. 손글씨·그림·수식은 이미지에 포함됩니다.
3. 전체 자료를 자동 순회하며 여러 페이지씩 Python 서버로 보냅니다. 서버가 Codyssey의 고정된 HTTPS API를 호출합니다.
4. 큰 자료는 중간 노트를 여러 차례 합쳐 최종 노트 한 권으로 만듭니다. 파일 번호와 PDF 쪽수를 근거로 남기도록 지시합니다.
5. 모델은 불확실한 판독을 표시하며 사용자가 고칠 수 있습니다. 개인 X 범위 제외는 사용자가 요청한 경우 적용합니다.
6. 대화는 최근 문답과 선택한 완성 노트를 참고합니다. 원본 PDF 이미지 전체가 질문마다 자동 전송되지는 않습니다.

## 안전한 키·자료 관리

방문자가 자신의 API 키를 입력하는 방식이 기본입니다. 키는 탭의 메모리에만 존재합니다. 서버 환경변수 키는 별도 접근 암호가 확인되어야 사용됩니다. 외부 사이트의 요청은 Origin 검사로 거절하고, API 리디렉션을 따라가지 않습니다. 원본에 포함된 지시문을 시스템 지시로 실행하지 않도록 프롬프트를 구성합니다. AI 결과는 HTML로 실행하지 않고 이스케이프한 뒤 표시합니다.

공유 버튼은 앱 주소만 전달합니다. PDF·노트·대화는 사용자 기기의 브라우저에 있습니다. 자료 삭제 시 관련 통합 노트·진행 기록·대화도 정리합니다. 기존 서비스의 사용자 자료와 강의 PDF는 새 배포에 포함하지 않습니다.

## 오류와 복구

- PDF 형식, 파일당 150MB, 암호·손상, 저장 공간 부족을 안내합니다.
- 누락·잘못된 키, 모델 ID, 사용 권한, 잔액, 호출 제한, 타임아웃을 구별합니다.
- 이미 완료한 읽기는 체크포인트로 보관하고 수동으로 이어갑니다. 실패 유료 요청을 자동 반복하지 않습니다.
- 이전 완성 노트는 새 노트가 완성될 때까지 유지합니다.
- 원본·요청 버전을 확인하여 다른 자료 시점의 결과가 섞이지 않도록 합니다.

## 확장 계획과 현재 한계

현재는 기기별 로컬 저장입니다. 계정 로그인·기기 동기화·공유 자료실은 향후 범위입니다. 앱스토어 배포를 위한 네이티브 패키지와 심사는 이번 결과물에 포함하지 않습니다. 실제 모델 정답률, 저사양 휴대폰의 대용량 PDF, OS 절전 중 복구, iOS 설치 후 저장 유지 여부는 추가 실기기 검증이 필요합니다.
