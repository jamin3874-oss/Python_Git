# 제출 전 실제 화면 증거

현재 자동 테스트 로그는 제공하지만 실제 UI 스크린샷은 수집하지 못했습니다. 아래를 실제 실행 화면에서 촬영해 이 폴더에 보완하세요. API 키 입력칸·접근 암호·개인 강의자료 내용은 화면에 노출하지 마세요.

1. **자료실 PC 화면**: 서비스 명칭, 업로드 영역, 세 주요 메뉴.
2. **여러 PDF 자료 화면**: 직접 만든 공개 가능한 자료 두 개를 올린 목록.
3. **요청과 전체 진행**: 요청사항과 자동 전체 노트 생성 진행 상태.
4. **실제 AI 완성 결과**: 출처 쪽수와 내용이 보이는 노트. 예시 노트를 실제 AI 결과로 표시하지 마세요.
5. **AI 후속 대화**: 질문과 설명이 이어지는 장면.
6. **오류 안내**: 키를 적용하지 않은 상태 또는 실제 호출 제한 등. 테스트 대역 오류와 실제 오류를 구분하세요.
7. **휴대폰**: 홈 화면 설치 아이콘, 앱 실행 후 하단 메뉴.
8. **배포 증거**: Vercel URL과 GitHub 소스 폴더가 보이는 화면.

AI 실제 테스트는 비용이 발생합니다. 본인 계정에서 연결 확인을 수행하고, 공개 가능한 2~3쪽 검증 PDF로 노트와 후속 질문을 확인하면 기본 흐름을 적은 비용으로 검증할 수 있습니다. 틀리기 쉬운 수식·숫자·손글씨는 원본 정답과 대조해 기록하세요.
