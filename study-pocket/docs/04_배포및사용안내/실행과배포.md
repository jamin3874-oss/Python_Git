# 실행과 배포

## 로컬 실행

일반 환경에서는 Node.js 22.13 이상, Python 3.12 이상을 설치하고 `app`에서 다음을 실행합니다.

```powershell
npm run build
python -B server.py
```

이 작업 PC에는 기존 프로젝트의 Python 가상환경과 `C:\앱\.tools`의 Node가 있어 그것을 사용해 검사했습니다. 앱 자체는 Python 표준 라이브러리만 사용하므로 새로운 PC에서 기존 가상환경을 그대로 복사할 필요가 없습니다.

## GitHub

사용자가 지정한 저장소: https://github.com/jamin3874-oss/Python_Git

기존 `1차 과제`, `2차 과제`, `Term Project` 파일을 보존하고 `study-pocket/` 폴더에 새 앱을 추가합니다. 그 안의 `docs/`에는 이번 과정·기획·검증·배포 문서가 있습니다. 별도 브랜치 `study-pocket-pwa-20261104`로 전달하며, 기존 기본 브랜치를 자동으로 덮어쓰지 않습니다.

Vercel이 기본 브랜치만 자동 배포하는 경우 이 브랜치를 검토·병합한 다음 연결하거나, Vercel의 해당 배포 브랜치 설정을 선택해야 합니다. 병합은 이번 작업 범위에 포함하지 않았습니다.

## Vercel

1. 본인 Vercel 계정에서 Add New Project → 위 저장소 Import.
2. 제출 앱이 들어간 브랜치를 선택하고 Root Directory를 **`study-pocket`**으로 설정.
3. Framework Preset은 **Other**, Build Command는 **`npm run build`**, Output Directory는 **`dist/public`**.
4. Node 22 이상을 사용합니다. Python API는 `api/ai.py`이며 `/api/ai`로 호출됩니다.
5. 각자 개인 키를 입력하는 배포에는 공용 키를 등록하지 않아도 됩니다.
6. 개인 서버 키를 쓸 때만 Vercel 환경변수에 `CODYSSEY_API_KEY`와 `STUDY_APP_ACCESS_TOKEN`을 secret으로 설정하고 재배포합니다. 두 값은 소스나 이 문서에 쓰지 않습니다.
7. 생성된 HTTPS URL에서 화면, API 연결, 실제 노트, 휴대폰 설치를 확인합니다.

2026-11-11 연결·배포를 완료했습니다. 실제 앱은 https://study-pocket-six.vercel.app 이고 프로젝트는 https://vercel.com/jaemin13/study-pocket 입니다. 프로덕션 브랜치는 `study-pocket-pwa-20261104`로 설정했습니다. Vercel의 과금·플랜·함수 실행 한도는 계정 설정과 최신 공식 문서에 따릅니다.
