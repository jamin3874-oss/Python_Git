# 휴대폰 설치와 다른 사람에게 전달하기

## Android

Chrome에서 공개 승인된 HTTPS 앱 주소를 열고 메뉴의 앱 설치 또는 홈 화면에 추가를 선택합니다. 앱 안의 사용·설치 안내에도 같은 내용이 있습니다. 브라우저가 설치 이벤트를 제공하면 앱 설치 버튼에서 설치 창을 엽니다.

## iPhone

Safari에서 HTTPS 앱 주소를 열고 공유 버튼 → 홈 화면에 추가를 선택합니다. 설치 버튼이 자동 설치를 강제할 수 없으므로 화면 안내를 따릅니다.

## 다른 사람에게 배포

접근 범위를 공개로 승인한 뒤 앱 주소를 전달합니다. 상대방은 자신의 Codyssey 키를 입력하고 자신의 PDF를 올립니다. 내 기기에 저장된 PDF·노트·대화는 링크 공유에 포함되지 않습니다. 내 키를 소스에 넣어 배포하지 않습니다.

이 앱은 PWA입니다. APK/IPA 파일을 배포하거나 앱스토어·Google Play에 등록한 상태는 아닙니다. 앱스토어 배포가 필요하면 패키징·서명·개발자 계정·심사를 별도 진행해야 합니다.

## 저장·오프라인

자료는 현재 기기의 브라우저 저장소에 있습니다. PC에서 올린 PDF가 휴대폰에 자동으로 나타나지 않습니다. 휴대폰에서 자료를 별도로 올리거나 PC의 완성 노트를 Markdown으로 다운로드해 전달하세요. 기기 간 공유 계정·클라우드 동기화는 향후 기능입니다.

한 번 로딩한 앱 셸과 저장 노트는 오프라인에서 열 수 있습니다. AI와 최초 PDF 보조 리소스 로딩에는 인터넷이 필요합니다. 휴대폰이 앱을 절전시키면 AI 작업이 중단될 수 있으며 다시 열어 이어가야 합니다. 개인 키는 앱 메모리 초기화·새로고침 후 다시 입력합니다.
