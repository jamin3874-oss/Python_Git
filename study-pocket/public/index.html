서버 환경변수로 설정한 개인 배포

서버에 키와 접근 암호를 모두 설정했을 때만 사용하세요.

API 주소는 copa.codyssey.kr로 고정됩니다. 키를 소스·내보내기·기기 저장소에 기록하지 않습니다.

연결 확인은 소량의 유료 API 요청을 보냅니다.

공부 시작

  1. 자료실에 여러 PDF를 한 번에 올립니다.
  2. API 설정에 본인의 키를 입력합니다.
  3. 공부 노트에서 요청을 적고 전체 노트를 만듭니다.
  4. AI 대화에서 노트를 참고해 질문을 이어갑니다.

휴대폰에 설치

Android: Chrome 메뉴 → 앱 설치 또는 홈 화면에 추가.
iPhone: Safari 공유 → 홈 화면에 추가.

자료와 저장

PDF·노트·대화는 이 기기의 브라우저에 보관됩니다. 기기 간 자동 동기화는 제공하지 않습니다. 브라우저 데이터를 삭제하면 자료도 사라지므로 중요한 노트는 다운로드하세요. 공유 버튼은 앱 주소만 공유합니다.

설치 후 한 번 사용한 앱 화면과 저장 노트는 오프라인에서 열 수 있습니다. AI 기능은 인터넷 연결과 유효한 키가 필요합니다.

작은 손글씨

DPI는 PDF를 이미지로 바꿀 때의 픽셀 밀도입니다. 전체는 기본 155 DPI로 읽고 작은 필기는 선택 영역만 최대 300 DPI로 확대합니다. 선명하지 않은 글자는 오독할 수 있으므로 원본과 대조하세요.
